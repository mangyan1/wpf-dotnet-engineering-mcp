# Engineering MCP 0.3.7-preview.4

This public-source pre-release packages the universal WPF/.NET Engineering MCP from a clean GitHub history. It contains no consuming-application-specific implementation.

## Universal WPF authorization

- Discovers modern and classic built WPF executable projects without executing MSBuild.
- Reads safe literal in-workspace centralized property imports as inert XML.
- Offers an explicit executable fallback with managed WPF metadata, workspace-containment, and reparse-point validation.
- Creates durable workspace-specific policies with exact executable paths, bounded source access, network deny, PII masking, screenshot redaction, and destructive/privileged actions disabled.

## Public release hygiene

- Apache-2.0 source, build scripts, release notes, SBOM generation, and security documentation are published together.
- The product-neutrality gate prevents consuming-application names and paths from entering the universal package.
- The code-signing policy documents current preview signatures and the planned SignPath Foundation trust path.
- Integration fixtures resolve the active Debug or Release build deterministically, so clean-checkout release validation cannot depend on stale local output.
