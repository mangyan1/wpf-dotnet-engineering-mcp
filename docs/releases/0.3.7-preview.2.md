# Engineering MCP 0.3.7-preview.2

This pre-release makes Engineering MCP open-source software under the Apache License, Version 2.0 and preserves mangyan1 attribution in the repository and packaged `NOTICE.txt`.

## Highlights

- Replaced the former source-available license with the OSI-approved Apache-2.0 license.
- Added SPDX `Apache-2.0` project and release-SBOM metadata.
- Bundled `LICENSE.txt` and `NOTICE.txt` in both portable and installed distributions.
- Added stable WPF selector handling for provider-owned native window chrome.
- Corrected DPI-aware target-window capture and conservative screenshot masking.
- Corrected zero-size text and native provider-chrome UI-audit false positives.
- Retained all 76 MCP tools and privacy-safe ASP.NET diagnostic correlation.

These preview artifacts are timestamped with a development self-signed certificate. Other machines must explicitly trust the included development certificate or wait for a future publicly signed release.
